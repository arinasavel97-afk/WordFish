# Emoji Policy

WordFish does not use emoji as part of its user interface.

Emoji should never be used for:

- headings
- buttons
- navigation
- backgrounds
- decorative elements
- empty states
- tooltips
- notifications
- badges
- labels

Instead, use one of the following:

• Finn (official WordFish mascot)

• WordFish illustrations

• SVG icons from the approved icon library

• Custom WordFish artwork

Emoji are only acceptable inside user-generated content (if that feature exists in the future).

The interface itself must remain emoji-free.

This rule applies to every future screen and component.

The goal is to maintain a consistent, polished, professional visual identity throughout the application.
