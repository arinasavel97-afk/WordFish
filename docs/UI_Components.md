# WordFish UI Components

Version: 1.0

This document is the master reference for every reusable UI component in the WordFish platform.

It defines the official component library used across the application.

Every new interface element should belong to one of these components.

If a new component is required, this document must be updated first.

---

# Design Philosophy

WordFish should feel:

• friendly
• playful
• premium
• modern
• clean
• calm
• educational

The interface should look consistent across every screen.

Components should be reusable.

Avoid one-off designs.

# Development Rules

Every new UI element must answer:

1. Which component group does it belong to?

2. Does a reusable component already exist?

3. Can an existing component be extended?

4. Does this require updating the Design System?

Never create one-off components unless absolutely necessary.
